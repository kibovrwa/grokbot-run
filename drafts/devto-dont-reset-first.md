Grok Bot is not grok.com.

Google still mixes them up. grok.com is chat plus Imagine and Voice. Grok Bot is a separate app: named teammates plus **one** cloud computer that keeps running after you close the laptop. There is no extra Grok Bot account. You sign in with the Cursor account that holds the plan and the usage.

This is not an official xAI or Cursor post. Packages stay on [x.ai/bot](https://x.ai/bot). What follows is the first-week order that keeps showing up in official Help, forum pins, and field notes — the parts people skip, then pay for.

## 1. A second Bot is not a fence

The roster looks like a team. The computer is not.

Every Bot on the account uses the same persistent machine. Cookies, files, and logins are shared. Life Bot and work Bot share a browser. Official docs and a Cursor forum pin say the same thing in different words: isolation is per **user**, not per Bot. Screens are not a security boundary.

If you would not put a credential on a shared laptop, do not put it on this computer. The longer write-up, with the forum pin and the official wording side by side, is here: [the Grok Bot computer is shared](https://grokbot.run/learn/computer/).

## 2. Twelve Bots on day one

Official Get started is short: name, one primary job, how it should work. Community tutorials independently converge on a Chief of Staff — one door that proposes specialists and reports blockers.

Chatty setup threads burn the weekly usage pool. The pool can spill into On-Demand with no loud in-app warning. Tests do **real** things: they navigate, they write files, they call connected tools.

So the first job should be boring and checkable. No connector. Stop at review. Do not send, delete, or pay.

A warm-up that matches the official pattern (outcome, source, constraint, deliverable, stop):

```
I attached one document. Give me (1) five bullets on what it says, and (2) every date, decision, and open question with a page or section cite. Leave the file unchanged.
```

If that works, you have a Bot. If it does not, fix login before you invent a twelve-Bot company.

## 3. Reset first

When the computer will not connect, Reset feels like the grown-up button. Official order is the other way around: Retry, restart the app, Recover, Update Agent Computer. Reset can drop unsynced work. If iOS still talks to the same roster, wait — that is often a clue the cloud side is fine.

Symptom-by-symptom notes, including “can’t reach your computer,” plugin OAuth, and Linux, are on the [Grok Bot not working](https://grokbot.run/troubleshooting/) page.

## What I will not quote as a price

There is no standalone Grok Bot SKU. Access is bundled with paid Cursor or a linkable SuperGrok / X plan, plus a limited usage trial on some accounts. Enterprise had a separate two-week org trial — read the dated news post, not a screenshot from August 12.

On a single fetch day, official pages still disagreed on whether Cursor Pro and base SuperGrok were on the list. Cursor Help and the August 26 news post included them; the xAI FAQ and Get started that day did not. Open the originals. A dated side-by-side, with no invented USD figures, is on the [pricing snapshot](https://grokbot.run/pricing/).

## Start here

1. Confirm you are not looking at grok.com.
2. Install from official entry points, sign in with Cursor.
3. Run one cited brief. Stop at drafts.
4. Treat the computer as shared. Recover before Reset.

That is the whole first week. Everything else is a specialist you have not earned yet.
