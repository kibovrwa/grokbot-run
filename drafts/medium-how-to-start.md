You searched “Grok Bot” and grok.com opened.

That is the wrong product. grok.com is chat, Imagine, and Voice. Grok Bot is a separate app: named teammates plus one cloud computer that keeps running after you close the laptop.

There is no extra Grok Bot account. You sign in with the Cursor account that already holds the plan and the usage.

This is not an official xAI or Cursor post. Packages stay on [x.ai/bot](https://x.ai/bot). What follows is the start order from official Get started and Cursor Help — the parts people skip because a blog told them to build a company on day one.

## Confirm you are allowed in

There is no consumer free tier and no standalone Grok Bot SKU. Access is bundled with a paid Cursor plan or a linkable personal SuperGrok / X plan. Some accounts also get a limited usage trial. Enterprise had a separate two-week org trial — read the dated news post, not a screenshot from mid-August.

On a single fetch day (4 September 2026), official pages still disagreed on whether Cursor Pro and base SuperGrok were on the list. Cursor Help and the 26 August news post included them. The xAI FAQ and Get started that day did not.

Do not pick a winner from a recap. Open the originals. A dated side-by-side, with no invented USD figures, is on this [Grok Bot pricing snapshot](https://grokbot.run/pricing/).

Two login facts that bite later:

- Linking SuperGrok or X Premium+ is a usage grant on that same Cursor account. It is not a second subscription. You cannot unlink it or move it yourself.
- Grok Bot needs cloud storage. If Cursor is still on Legacy Privacy Mode, the computer may not start. Fix the data setting before you blame the download.

## Install, then Sign in with Cursor

Official order is short. Download from the official entry points. Open the app. Choose Get started, or Sign In with Cursor in settings. Finish Cursor auth in the browser popup. Come back to the app.

If your org uses SSO, stay on the org flow. Do not open a personal Cursor account “just to try the Bot.”

First-run walks Bots, the shared computer, and routines, then asks which tools you use. Those answers only change suggestions. They do not connect Gmail, calendar, or Slack for you.

The computer initializes in the background. The last screen is a teammate, not a marketplace. Stop there.

The click-by-click order, with the official Get started and Cursor Help pages next to it, is on [how to install Grok Bot and log in with Cursor](https://grokbot.run/learn/install/).

## The first job should be boring

Official Get started wants five parts in the request: outcome, source, constraint, deliverable, and when to stop for review.

Cursor Help is even shorter: name, shape, color, title, then describe the outcome in a new chat.

That is enough. You do not need a twelve-Bot roster, a connector, or a 2,000-word system prompt.

Tests do real things. They navigate. They write files. They call connected tools. Chatty setup threads also burn the weekly usage pool, and the pool can spill into On-Demand with no loud in-app warning.

So the first job is a cited brief on one file. No connector. Leave the file unchanged. Do not send, delete, or pay.

Paste this:

> I attached one document. Give me (1) five bullets on what it says, and (2) every date, decision, and open question with a page or section cite. Leave the file unchanged.

If that works, you have a Bot. If it does not, fix login before you invent a company.

## Then pin one door

Community tutorials independently land on the same shape: you mainly talk to one pinned Chief of Staff. It proposes specialists, hands off work, and reports blockers. You do not open a Bot for every sub-task.

Official docs never require that architecture. They only ask for a short name, one primary job, and how it should work. The Chief of Staff pattern is a community convention that keeps the weekly pool and the shared computer from exploding on day one.

After the file brief works, pin one Bot and stop creating more until it can report a blocker. A first “real door” that still stops at drafts:

> You are my only door today. Review yesterday across my inbox, calendar, and meeting notes against the priorities I pasted. Return only items that map to those priorities. For each: source, why it matters, the next step, and whether I owe a decision. Do not send messages, create more Bots, or change meetings.

More copyable jobs, and why “Chief of Staff first” shows up in independent write-ups, are on [how to use Grok Bot after login](https://grokbot.run/learn/first-bot/).

## What this first hour is not

A second Bot is not a private machine. Every Bot on the account uses the same persistent computer. Cookies, files, and logins are shared. If you would not put a credential on a shared laptop, do not put it on this computer.

When the computer will not connect, Reset is not the first button. Official order is Retry, restart the app, Recover, then Update Agent Computer. Reset can drop unsynced work.

Those two traps are a different article. The first hour is only this: right product, Cursor login, one cited brief, one door.

## Start here

1. Confirm you are not looking at grok.com.

4. Run the file brief. Stop at drafts.
5. Pin one Chief of Staff. Do not create the rest of the company yet.
